whisper.cpp turns audio and video into text. It runs on your computer, so your files never go to a server.

## Install whisper.cpp

whisper.cpp is installed the first time you open Transcribe and choose to install it. On macOS and Linux it is built from source, which needs `git`, `cmake` and a C/C++ compiler.

## Pick a model

Whisper models are downloaded from Hugging Face when you pick one. Larger models are more accurate, but slower.

| Model | Size |
|---|---|
| Tiny | about 75 MB |
| Base | about 142 MB |
| Small | about 466 MB |
| Medium | about 1.5 GB |
| Large | about 2.9 GB |

## Pick a language

Leave the language on **Detect automatically**, or pick one of 12 languages: English, Spanish, French, German, Italian, Portuguese, Chinese, Japanese, Korean, Arabic, Hindi and Russian. Naming the language helps with short or noisy clips.

## Transcribe files

Drop files on the Transcribe page, or select them to browse. You can also paste the full path of a file on this computer. Each file joins the queue and is transcribed in turn. A finished transcript is saved next to the file it came from, in the formats picked under **Transcript files** in [Settings](/docs/guides/settings). Plain text is the default.

## Save a transcript

Press **Save** on a finished file and pick a format. **Save all** does the same for the whole queue.

| Format | What it is for |
|---|---|
| Text (`.txt`) | The words as one paragraph |
| Subtitles (`.srt`) | Subtitles with timestamps. Most video players load them when they sit next to the video with the same name. |
| Web subtitles (`.vtt`) | Subtitles for web video players |
| Lyrics (`.lrc`) | One timed line per sentence, for music players |
| Spreadsheet (`.csv`) | Start and end in milliseconds, and the text |
| Tab separated (`.tsv`) | The same columns, separated by tabs |
| JSON (`.json`) | The text, and each segment with its start and end in seconds |

A file you dropped on the page is a temporary copy, so nothing is saved next to it. Use **Save** instead.

## Transcribe every download

Turn on **Transcribe after download** on the YouTube or Instagram page, or **Transcribe** on the Batch download page, and every finished download is transcribed too. The model, the language and the transcript files are set in [Settings](/docs/guides/settings).

In a bulk download each file is transcribed right after it downloads, before the next one starts. The progress window shows which file is being transcribed and only finishes when the last transcript is saved. If Whisper or the chosen model is not installed yet, the files still download and the window says why they have no transcript.
